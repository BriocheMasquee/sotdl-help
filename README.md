# Shadow of the Demon Lord — Help modules for Encounter+ / Modules d'aide pour Encounter+

Usage guides for the **Shadow of the Demon Lord** system for [Encounter+](https://www.encounter.plus) (system: [BriocheMasquee/sotdl](https://github.com/BriocheMasquee/sotdl)).
Guides d'utilisation du système **Shadow of the Demon Lord** pour *Encounter+*.

| Module | Language / Langue | Status / État |
|---|---|---|
| **Aide OSD** (`aide-osd`) | Français | Available / Disponible |
| **Help SotDL** (`help-sotdl`) | English | Coming soon / À venir |

## Install / Installation

- **From Encounter+ / Depuis Encounter+** : the modules are listed in the system's recommended content / les modules figurent dans les contenus recommandés du système.
- **By hand / À la main** : download the `.module` file of the [latest release](../../releases/latest) and import it in Encounter+ / téléchargez le fichier `.module` de la [dernière release](../../releases/latest) et importez-le dans Encounter+.
- **Players' PDF / PDF pour les joueurs** : `Aide_OSD_joueurs.pdf`, attached to each [release](../../releases/latest) / joint à chaque release.

## What they contain / Contenu

How the system works (character sheet, creation, level up, play, GM cards, combat tracker, settings) and a reference of the entity forms. They contain **no rule, text or illustration of the game**; the example entities are invented and provided for tutorial purposes only.
Le fonctionnement du système (feuille de personnage, création, montée de niveau, jeu, cartes du MJ, suivi de combat, réglages) et une référence des formulaires d'entités. Ils ne contiennent **ni règle, ni texte, ni illustration** du jeu ; les entités d'exemple sont inventées et fournies à des fins de tutoriel.
